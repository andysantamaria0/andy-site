Customer · Post-QR-scan
The Flow
I
Scan. QR sticker on the kiosk opens bg.nyc/u/001. No app, no account.
II
Pay. Apple Pay / Google Pay by default. Stripe handles it.
III
Code. 6-digit code issued. Session logs to Supabase. Attendant verifies, opens the door.
IV
Receipt. Email on tap. Cream stock printed on exit for those who want the object.
Edge cases
Payment fails — card retry, fall back to attendant-swiped card.
Code expires (15 min) — refund prompt on the attendant side.
Customer already paid — session restored from email / phone.

VI · Build Plan

From Prototype to Product.

This page is a single HTML file. The real thing ships as Next.js + Supabase + Stripe, deployed on Vercel. Here's the plan when you green-light it.

Stack
Frontend — Next.js 16 (App Router), Tailwind, React 19
DB — Supabase (Postgres, Realtime, Auth)
Payments — Stripe Checkout w/ Apple/Google Pay
Hosting — Vercel (browngloveny.com)
Email — Resend (receipts)
Mobile — PWA first; Expo/React Native port if needed
Schema (first cut)
units · (id, slug, location, is_active)
sessions · (id, unit_id, code, status, paid_at, expires_at)
payments · (id, session_id, stripe_pi, amount, method)
attendants · (id, email, name)
shifts · (id, attendant_id, unit_id, start, end, tips)
cleanings · (id, session_id, attendant_id, checklist_json)
tray_swaps · (id, unit_id, attendant_id, tray_qr)
issues · (id, unit_id, attendant_id, category, body)
Build Order
I
Scaffold. Next.js + Tailwind + design tokens locked to this palette/type system. Reusable <Button> <Pill> <Tile> components.
II
Customer flow end-to-end. /u/[slug] → Stripe Checkout → success page with 6-digit code → Supabase session row.
III
Attendant app. Supabase Auth, shift + verify + checklist + tray-swap + issues. PWA manifest for home-screen install.
IV
Admin console. Live units list, session log, KPIs. Restrict by role.
V
QR sticker. Printable design for Unit 001 — brass wordmark, sunburst, URL beneath in JetBrains Mono.
VI
Deploy. Vercel · browngloveny.com + app subdomain · admin subdomain · Stripe webhook · Supabase RLS.
